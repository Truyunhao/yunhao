液态玻璃 · 新标签页  v1.5.4
========================================

安装方法（Chrome / Edge 等 Chromium 内核浏览器）

  1. 把本压缩包解压到一个不会被删掉的文件夹里
     （扩展装好后会一直读这个文件夹，别解压到临时目录）。

  2. 打开浏览器，地址栏输入：  chrome://extensions
     （Edge 是  edge://extensions）

  3. 打开右上角的「开发者模式 / Developer mode」开关。

  4. 点左上角「加载已解压的扩展程序 / Load unpacked」，
     选中第 1 步解压出来的那个文件夹（里面应该有 manifest.json）。

  5. 新建一个标签页即可看到效果。

注意：Chrome 不允许把 .zip 直接拖进扩展页面加载，
      必须先解压再「加载已解压的扩展程序」。
      请确认文件夹里能看到 manifest.json 这一个文件，
      如果是多套了一层文件夹，请选中里面那一层。

主要功能
----------------------------------------
· 时间显示：字体、字号、粗细、字间距、颜色（可自动适配背景对比度）
· 多引擎搜索：百度 / 必应 / Google
· 链接按钮：多面板 + 多分类，可拖动排序
    · 分类条上：新增分类 / 添加链接 / 编辑
    · 分类条右【外】侧 3px（悬停面板头时淡入）：上移 / 下移 / 新增面板 / 删除此面板
      （那 3px 空隙由 .panel-head::after 这块"悬停桥"补上，鼠标从分类条滑出去不会断 hover；
        若视口右边实在放不下 —— 比如「区域宽度」被容器夹住只剩 24px 余量 —— 会自动收回
        分类条内部并让分类条让出右内边距，不会被窗口边缘截掉半截）
    · 每个链接按钮右上角：修改（删除链接在「修改链接」弹窗的右上角）
· 静态壁纸：本地上传、多张轮播（可设间隔与随机/顺序，默认「无」= 不轮播）
· 动态壁纸：上传视频（mp4 / webm 等），选中的视频在新标签页循环播放，
            设置页的壁纸预览同步循环
· 液态玻璃效果：折射深度、棱边宽度、柔化、曲率、模糊、色散、高光、
                通透度、染色强度与颜色，另有 6 套预设
· 高光显示：一键开关分类标签 / 搜索引擎按钮 / 引擎切换容器的高光描边
· 数据：导出 / 导入 / 恢复默认

关于动态壁纸（有必要知道的两点）
----------------------------------------
· 视频二进制存在浏览器的 IndexedDB 里（不在 chrome.storage，也不进导出的 JSON）。
  所以「导出数据」只含元数据；把扩展换台机器用时，视频需要重新添加。
· 视频壁纸生效时，液态玻璃的「边缘折射」靠把当前帧拷成图片喂给折射层来保留
  （约 10fps，单帧太慢会自动退到约 5fps；标签页不可见时暂停）。
  如果你更在意省电，可以在设置里关掉「折射」。

默认设置说明
----------------------------------------
首次安装（本地无存档）时使用下面这套默认值：
· 搜索引擎 Google，4 个分类：常用 / 开发 / 工具 / 影音（_id 固定）
· 顶部距时间模块 9vh，时间模块距搜索模块 6vh，搜索模块距链接模块 9vh
· 区域宽度 1200px，按钮宽度 126px，按钮高度 50px，按钮圆角 10px
· 图片圆角 50%（正圆），按钮间距 14px，按钮内容靠左
· 时间字体颜色固定 #ffffff（不自动适配背景）
· 壁纸轮播间隔为「无」（不自作主张换壁纸）；自定义间隔上限 9999 分
· 默认壁纸在 js/default-wallpaper.js 里（一张 2560×1440 的 JPEG DataURL），
  它也作为静态壁纸列表里的第一张并被选中。
  想换掉它：跑  node _verify/mkdefault.js <新图片路径>  重新生成该文件即可；
  手改也行 —— 替换 window.LG_DEFAULT_WALLPAPER 与 LG_DEFAULT_WALLPAPER_NATURAL。
· 已经装过旧版的用户不会被清空数据：升级时只把这张默认壁纸补进列表并选中，
  分类 / 链接 / 主题 / 液态参数都保留。想整体回到出厂值，可在新标签页控制台执行
    __liquidGlass.resetDefaults()
